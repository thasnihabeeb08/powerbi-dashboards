# 📊 Power BI Dashboard Portfolio

A collection of Power BI dashboards built to analyze real-world business problems across e-commerce, banking, retail, and healthcare domains. Each dashboard demonstrates data cleaning, DAX measures, interactive visualizations, and business storytelling — including one dashboard with integrated Machine Learning predictions.

## 📁 Dashboards Included

### 1️⃣ E-commerce Sales Dashboard
**Folder:** `dashboard-1/`

Analyzes e-commerce sales performance to uncover trends in revenue, profitability, and customer demand.

**Key Metrics:** Sales, Quantity, Profit (with averages)
**Breakdowns:** By Category, Region, Product, and Order Date trend
**Visuals:** KPI cards, bar chart, line chart, donut charts, interactive slicers

---

### 2️⃣ Bank Fraud Detection Dashboard
**Folder:** `dashboard-2/`

Monitors banking transactions to detect and analyze fraudulent activity patterns.

**Key Metrics:** Total Transactions, Fraud Transactions, Fraud Rate %, Fraud Amount
**Breakdowns:** By Payment Method, Merchant Category, Fraud Type, and Month
**Visuals:** Trend line chart, treemap, column chart, donut chart, slicers

---

### 3️⃣ Amazon Product Performance Dashboard
**Folder:** `dashboard-3/`

A 4-page multi-dimensional analysis of Amazon product performance, pricing, and customer engagement.

**Pages:**
- **Executive Overview** — high-level KPIs: total products, reviews, average price, weighted rating, engagement score
- **Product Performance Analysis** — top-performing products, rating distribution, popularity by category
- **Customer & Pricing Insights** — price vs. rating correlation, pricing segments, review analysis
- **Product Details** — deep-dive table view filterable by category

**Visuals:** Ribbon chart, scatter chart, treemap, pivot tables, combo charts, slicers

---

### 4️⃣ Hospital Analytics Dashboard (with Machine Learning Insights)
**Folder:** `dashboard-4/`

A 5-page healthcare analytics dashboard combining operational hospital metrics with **integrated Machine Learning predictions**.

**Pages:**
- **Executive Overview** — total patients, billing, average length of stay, patient age, and **prediction accuracy**
- **Hospital Performance** — billing and patient volume comparison across hospitals, doctor counts
- **Machine Learning Insights** — Predicted vs. Actual Test Results with model accuracy tracking
- **Hospital Details** — hospital-wise deep dive (billing, patients, insurance, admission type)
- **Patient Details** — patient-level breakdown by medical condition, billing, and test results

**Visuals:** Line charts, clustered bar/column charts, donut charts, pivot tables, 100% stacked bar chart

## 🛠️ Tools & Skills Used
- **Power BI:** Data modeling, DAX measures, interactive dashboards, multi-page reports
- **Data Cleaning:** Structured raw datasets into analysis-ready tables
- **Machine Learning Integration:** Connected ML model predictions (Actual vs. Predicted results) directly into a Power BI report
- **Business Domains Covered:** E-commerce, Banking/Fraud Detection, Retail/Product Analytics, Healthcare
